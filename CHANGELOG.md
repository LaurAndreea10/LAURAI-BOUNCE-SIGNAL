# Changelog

Toate modificările importante ale proiectului sunt păstrate aici.

## 3.1.0 — 2026-09-04

### Îmbunătățit

- Etichete accesibile pentru comenzile care afișează doar pictograme.
- Anunțarea schimbării stării misiunii prin `role="status"` și `aria-live`.
- Culoare de temă pentru bara browserului pe mobil.
- Versiune vizibilă sincronizată în interfață.

## 3.0.0 — 2026-08-24

- Mission Control complet cu scenarii, analiză AI, telemetrie și fallback channels.
- Istoric local, export JSON/TXT, XP, achievements și command palette.
- Interfață RO/EN, teme, contrast ridicat și reduced motion.
